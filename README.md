## 愛知県の天候チェッカー（個人開発）

愛知県内の天候情報をリアルタイムに取得・表示するWebアプリケーションです。
外部API連携の実装スキル習得や、アプリケーションライクな画面デザイン、React/TypeScriptでの状態管理・コンポーネント設計の実践を目的に開発しました。


##  特徴

- **外部APIとの連携: リアルタイムな天候データを外部API（Weather API）から非同期取得し、画面へ即座に反映。
- **useState や useEffect などのReact Hooksを活用し、データの単一方向フローと不要な再レンダリングを抑えた設計。


##  技術構成

- **フロントエンド: React, TypeScript, CSS
- **ビルドツール: Vite
- **デプロイ・ホスティング: Vercel
